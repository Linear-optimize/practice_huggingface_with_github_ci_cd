# Hugging Face + GitHub CI/CD Practice

A minimal project for training and evaluating a sentiment analysis model with a lightweight workflow.

## What’s Included
- `train.py`: model training script
- `datasets/imdb_balanced_10k.csv`: sample dataset
- `requirements.txt` / `pyproject.toml`: dependencies
- `model.joblib`: saved model artifact

## Quick Start
```bash
pip install -r requirements.txt
python train.py
```
